# Pysnake 🐍

**一个为学习而生的贪吃蛇项目。** 每一行核心代码都配有中文注释，从 GUI 编程、游戏循环到 AI 寻路，边玩边学——适合 Python / JavaScript 初学者把"课本知识"变成"能跑的游戏"。

同一套游戏逻辑用两种语言各实现一遍：

- 🐍 **`game.py`** —— Python + tkinter 桌面版（注释最详细，适合精读）
- 🌐 **`pysnake.html`** —— 单文件网页版（HTML + CSS + JS），双击即玩，方便和 Python 版对照学习

## 📖 学习路线（建议按此顺序读代码）

> 📄 **配套文档：[源码导读 docs/GUIDE.md](docs/GUIDE.md)** —— 逐模块讲解设计意图、关键代码片段、踩坑记录与动手练习，建议与本文配合使用。

1. **常量区** —— 把"魔法数字"集中管理的思想
2. **界面切换** —— Python 用 `tkraise()` 堆叠 Frame，网页用 CSS `display` 切换 div
3. **绘制系统** —— 网格坐标 vs 像素坐标；标签/离屏画布等"只画一次"的优化
4. **游戏循环** —— `root.after` / `setTimeout` 自我续期的定帧节奏
5. **核心逻辑** —— 移动、碰撞判定顺序、金苹果免疫的状态机
6. **NPC AI** —— 危险格集合 + 曼哈顿距离寻路 + 概率决策
7. **工程细节** —— epoch 代次校验、按键焦点防误触、本地持久化

## 🧠 概念地图：游戏功能 ↔ 编程概念

| 游戏功能 | 涉及的编程概念 |
|---|---|
| 蛇的移动与变长 | 列表操作、`insert`/`pop` |
| 游戏循环 | 定时器、事件驱动编程 |
| 三种界面切换 | 布局容器、视图路由 |
| NPC 蛇 AI | 集合运算、贪心算法、随机数决策 |
| 金苹果/火箭 | 布尔状态机、时间戳比较 |
| 重开不串场 | epoch 代次校验（闭包捕获） |
| 输入用户名 | 事件冒泡与焦点管理 |
| 排行榜 | JSON / localStorage 持久化 |
| 棋盘格背景 | 离屏画布 / 标签批量管理 |

**双版本对照**是本项目最大的学习价值：同一个功能（如游戏循环、碰撞判定）在 Python 和 JS 里各看一遍，能直观理解"语言不同、思路相通"。

## ✨ 游戏特性

- 🤖 NPC 蛇：随机长度（5~8），会躲避边界和你、会抢苹果成长，80% 概率规避玩家，被击杀 +1000 分
- 🍎 金苹果：免疫一次死亡（撞墙或撞 NPC 时自动随机转向），不可叠加
- 🚀 小火箭：拾取后按 Q 使用，3 秒内速度翻倍
- 🏆 本地排行榜：记录用户名与分数，支持删除单条 / 清空全部
- 🎨 手绘风格 UI：棋盘格背景、带眼睛的圆蛇、苹果果柄叶子等细节
- ⌨️ 完整按键支持：ESC 退出/返回、空格暂停、R 重开

## 🕹️ 操作说明

| 按键 | 功能 |
|---|---|
| 方向键 | 控制蛇移动 |
| 空格 | 暂停 / 继续 |
| Q | 使用小火箭（加速 3 秒） |
| R | 游戏结束后重新开始 |
| ESC | 游戏/排行榜界面返回标题；标题界面退出 |

**规则**：吃到苹果 +10 分并变长；撞到 NPC 蛇任意部位阵亡；NPC 的头撞到你的身体则它被击杀，你 +1000 分；撞墙时若持有金苹果免疫则自动随机转向逃生。

## 🚀 运行方式

### 网页版（零安装，推荐先玩这个）

用浏览器（Chrome / Edge 等）直接打开 `pysnake.html`。

### Python 桌面版

需要 Python 3（tkinter 为内置库，无需安装任何第三方依赖）：

```bash
python game.py
```
